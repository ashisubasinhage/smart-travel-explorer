# 🌍 Smart Travel Explorer

A beginner-friendly but polished travel discovery web app built to demonstrate the next step after a static HTML/CSS/JavaScript project.

## ✨ What it does
- Searches live country data with the **REST Countries API**
- Filters by region and travel style
- Sorts destinations
- Opens a destination detail view
- Fetches current weather using **Open-Meteo**
- Saves favourite destinations with **localStorage**
- Generates a simple multi-day trip plan from user input
- Handles loading, API errors and offline fallback data
- Responsive layout for desktop, tablet and mobile

## 🧠 Skills demonstrated
`HTML5` · `CSS3` · `JavaScript` · `fetch()` · `async/await` · `JSON` · DOM manipulation · event listeners · array methods · filtering/sorting · localStorage · error handling · responsive design

## 🔌 APIs
- REST Countries: https://restcountries.com/
- Open-Meteo Weather: https://open-meteo.com/
- Open-Meteo Geocoding: https://open-meteo.com/en/docs/geocoding-api

No API key is required.
